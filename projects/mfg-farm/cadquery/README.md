# ModRun CadQuery Design Files

Parametric Python source for the ModRun cable management family.
All parts are generated by running the scripts below.

## Files

| Script | Produces | Purpose |
|--------|----------|---------|
| `modrun_rail.py` | `modrun_rail_clip.stl`, `modrun_rail_adhesive.stl` | Mounting rails (two base variants) |
| `modrun_clips.py` | `modrun_clip_3mm.stl`, `modrun_clip_6mm.stl`, `modrun_clip_12mm.stl` | Press-fit cable clips |

STL outputs land in `../stl/`.

---

## Generate / Regenerate STLs

```bash
# Activate the CadQuery environment
source /home/awank/python_env/bin/activate

# Build all parts
cd projects/mfg-farm/cadquery
python modrun_rail.py
python modrun_clips.py
```

## How to Adjust Parameters

Every script starts with a `PARAMETERS` block at the top — all dimensions are
named variables. Change them there, then re-run the script.

### Rail parameters (`modrun_rail.py`)

| Parameter | Default | What it controls |
|-----------|---------|-----------------|
| `RAIL_LENGTH` | 200 mm | Overall rail length. Scale up for longer desk runs. |
| `RAIL_WIDTH` | 24 mm | Outer rail width. |
| `RAIL_HEIGHT` | 16 mm | Rail height from base to top. |
| `CHANNEL_WIDTH` | 16 mm | Inner cable channel opening. Should be ≥ thickest cable bundle width. |
| `CHANNEL_DEPTH` | 10 mm | How deep the cable channel is. |
| `SLOT_PITCH` | 30 mm | Spacing between clip-slot centres along the rail. |
| `CLIP_DESK_THICK` | 25 mm | **Desk variant**: adjust to match your desk edge thickness. |
| `CLIP_ARM_LEN` | 32 mm | **Desk variant**: how far the lower arm extends under the desk. |
| `ADHESIVE_PAD_DIA` | 20 mm | **Adhesive variant**: diameter of the adhesive pad pockets. |

### Clip parameters (`modrun_clips.py`)

| Parameter | Default | What it controls |
|-----------|---------|-----------------|
| `BODY_WIDTH` | 18 mm | Clip width (across the rail direction). |
| `BODY_DEPTH` | 10 mm | Clip front-to-back depth (scales with cable diameter too). |
| `SADDLE_WALL` | 2 mm | Wall thickness surrounding the cable bore. |
| `SNAP_THICKNESS` | 1.8 mm | Snap arm wall thickness. Thinner = easier flex; use PETG or TPU. |
| `SNAP_GAP` | 0.4 mm | Print-clearance in snap opening. Increase if layers are bonding. |
| `VARIANTS` | 3/6/12 mm | Cable diameter variants to generate. Add more diameters as needed. |

**To add a new cable diameter** (e.g. 8 mm):
```python
VARIANTS = {
    "3mm":  3.0,
    "6mm":  6.0,
    "8mm":  8.0,   # ← add this
    "12mm": 12.0,
}
```

## Print Settings (Recommended)

| Setting | Rail | Clips |
|---------|------|-------|
| Material | PLA or PETG | PETG (snap arm needs flex) |
| Layer height | 0.2 mm | 0.2 mm |
| Infill | 20% | 30% |
| Orientation | Flat-side down | Flat-side down |
| Supports | Not needed | Not needed |
| Wall loops | 3 | 4 |

## Dependency Notes

CadQuery requires the `cadquery-ocp` extension for the OCCT geometry kernel:

```bash
/home/awank/python_env/bin/pip install cadquery-ocp
```

`nlopt` must be copied from the system package (pip build fails on aarch64):
```bash
sudo apt-get install -y python3-nlopt
cp /usr/lib/python3/dist-packages/_nlopt.cpython-311-aarch64-linux-gnu.so \
   /home/awank/python_env/lib/python3.11/site-packages/
cp /usr/lib/python3/dist-packages/nlopt.py \
   /home/awank/python_env/lib/python3.11/site-packages/
```

CadQuery 2.3.0 also requires a one-line patch to `shapes.py` for OCP 7.9 compatibility
(the `HashCode` API changed). The patch is already applied in `/home/awank/python_env`.
